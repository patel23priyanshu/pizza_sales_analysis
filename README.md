# 🍕 Pizza Sales Analysis using SQL

## 📌 Overview

This is a learning project created to practice SQL by analyzing a pizza sales dataset. The project focuses on writing SQL queries to solve real-world business problems using relational databases.

Through this project, I practiced retrieving business insights such as revenue analysis, customer ordering patterns, product performance, and sales trends.

---

## 🎯 Objectives

- Understand relational database concepts
- Practice SQL queries on multiple related tables
- Improve skills in Joins, Aggregations, CTEs, and Window Functions
- Solve business-oriented SQL problems

---

## 🗂️ Database Schema

The project consists of four tables:

- **orders** – Stores order date and time
- **order_details** – Stores ordered pizzas and quantities
- **pizzas** – Stores pizza size and price
- **pizza_types** – Stores pizza names, categories, and ingredients

---

## 📊 Business Questions Solved

### Basic
- Total number of orders
- Total revenue generated
- Highest-priced pizza
- Most common pizza size
- Top 5 most ordered pizza types

### Intermediate
- Quantity sold by pizza category
- Hourly order distribution
- Category-wise pizza distribution
- Average pizzas ordered per day
- Top 3 pizza types by revenue

### Advanced
- Revenue contribution of each pizza type
- Cumulative revenue over time
- Top 3 revenue-generating pizzas in each category
